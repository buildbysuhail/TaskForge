# 🚀 TaskForge – MERN Project Management App

TaskForge is a full-stack Project Management Application built using the MERN Stack.  
It allows users to securely register, log in, and manage tasks efficiently.

---

## 🧠 Tech Stack

**Frontend**
- React (Vite) -- frontend library
- Axios -- API Communication
- React Router -- Routing
- CSS -- Styling

**Backend**
- Node.js -- Server of Taskforge
- Express.js -- Web framework
- MongoDB -- DataBase
- Mongoose -- MongoDB ODM
- jsonwebtoken --JWT Authentication 
- bcrypt -- password hashing

---

## ✨ Features

- 🔐 User Authentication (Register & Login)

- 📝 Create Tasks
